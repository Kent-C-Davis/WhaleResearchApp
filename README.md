# Whale Research App

## Requirements

- Visual Studio 2022 17.14 or later
- .NET 9 SDK
- .NET MAUI workload
- Android SDK (for Android emulator/device testing)

## Solution Structure

- WhaleResearchApp
  - .NET MAUI Blazor Hybrid application
  - Runs on Android, iOS, Mac Catalyst, and Windows

- WhaleResearchApp.Shared
  - Shared Razor components and UI

- WhaleResearchApp.Web
  - Browser-based Blazor application
